# Xogot for Godot Users (Orientation & Interface Differences)

This project accompanies Joseph Smithberger’s introductory video for developers
who already know **Godot** and want to get oriented in **Xogot**, the native
iPad & iPhone version of the Godot Engine.

The goal of this guide is *not* to teach Godot itself, but to show where tools
have moved, what has been simplified for touch interaction, and how Xogot adapts
the Godot workflow for a mobile environment.

---

## Overview

Xogot rethinks the Godot editor for touch-first workflows.  
Instead of shrinking the desktop UI onto a smaller screen, Xogot reorganizes
panels, introduces gesture-based interactions, and streamlines common tasks to
make creation practical on iPad and iPhone.

This video and project highlight key differences, design decisions, and tips to
help Godot users feel immediately at home.

---

## Topics Covered
- Why Xogot’s UI differs from desktop Godot
- Differences in the start screen and project workflow
- Xogot’s touch-optimized node creation dialog
- Using Xogot’s Inspector to access properties, signals, input mapping, autoloads, shader globals, and more
- What works the same, and what works differently, in Xogot
- How to deploy your game to the web
